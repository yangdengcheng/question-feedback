工单闭环四步走

客户提交 → 研发处理 → 客户确认
待处理
PENDING
客户提交工单，附截图 / 日志；主管与管理员即刻收到通知
处理中
PROCESSING
研发认领或被分配；可转交，转交说明必填
已解决
RESOLVED
处理完成，客户自动收到通知
已关闭
CLOSED
客户「确认解决」闭环；未解决可退回，已关闭可重新打开
02

按角色看你能做什么

客户（电力交易员）

仅看自己创建的工单
  • 新建工单、上传附件
  • 评论沟通、跟进度
  • 确认解决 / 退回 / 重开
  • 浏览、下载工具包

研发

我创建的 + 分配给我的
  • 看板掌握待办与统计
  • 变更状态、转交工单
  • 评论协作留痕
  • 维护工具包与版本

管理员 + 研发主管

全部工单 + 后台管理
  • 分配处理人、跟进度
  • 用户：建号 / 停用 / 角色
  • 工单 / 用户批量删除
  • 删除不可恢复，需谨慎
